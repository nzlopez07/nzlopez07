### 🍁 Sobre Mí

¡Buenas! Soy **Nicolás**. Actualmente curso el **4° año de Ingeniería en Sistemas de Información** en la **UTN - Facultad Regional Córdoba** (con paso previo por Ciencias de la Computación en la UNC). Me motiva profundamente entender cómo interactúan los sistemas por dentro: desde los protocolos de red y la seguridad perimetral hasta el software en producción.

- 🎓 **Orientación & Carrera:** Enfocado en la carrera hacia la **Ciberseguridad**, la **Gestión de Redes de Información** y la infraestructura segura.
- 🤖 **Experiencia en IA:** Me desempeñé como **QA Junior en Inteligencia Artificial para Outlier**, evaluando, testeando y refinando la precisión, razonamiento y alineamiento de respuestas en LLMs avanzados.
- 🏠 **Filosofía Homelab & Soberanía de Datos:** Administro mi propio nodo doméstico 24/7 impulsado por Docker, Caddy y túneles Cloudflare Zero Trust.
- 🛠️ **Desarrollo:** Fuerte afinidad con **Python** (**FastAPI**, **Flask**), **React / TypeScript**, aplicaciones móviles híbridas (**Capacitor**) y herramientas de automatización.

### 🏠 Arquitectura Homelab & Servicios Autohospedados

Mantengo mi propio nodo doméstico 24/7 para desarrollo, pruebas y producción privada, operando bajo estándares de seguridad y contención:

```text
                 [ Internet / Clientes Móviles ]
                                │ 
                 (Túnel Seguro Cloudflare Zero Trust)
                                │
  ┌─────────────────────────────▼───────────────────────────────────┐
  │                 HOMELAB SERVER (Debian Linux)                   │
  │                                                                 │
  │  🌐 APLICACIONES & HUBS   🛡️ RED & DNS           🔐 SEGURIDAD  │
  │  ├─ Portfolio Hub         ├─ AdGuard Home (DNS)  └─ Vaultwarden │
  │  ├─ Kairós UTN            └─ Tailscale Mesh Net                 │
  │  ├─ El Canuto                                                   │
  │  └─ Track Backend         📈 TELEMETRÍA          ⚡ REVERSE PROXY│
  │                           ├─ Uptime Kuma         └─ Caddy Proxy │
  │  📦 ORQUESTACIÓN          └─ Glances Metrics                    │
  │  └─ Docker Compose                                              │
  └─────────────────────────────────────────────────────────────────┘
```

* 🛡️ **Seguridad Perimetral:** Cloudflare Zero Trust Tunnels y Tailscale Mesh.
* ⚡ **Reverse Proxy:** Caddy gestionando nombres de dominio, compresión y certificados TLS automáticos.
* 📈 **Disponibilidad & Métricas:** Uptime Kuma para chequeo continuo de latencia/uptime y Glances para telemetría de hardware.
* 🔐 **Privacidad & Credenciales:** AdGuard Home para filtrado DNS de red y Vaultwarden con backups programados.
