### 🍃 Sobre Mí

¡Buenas! Soy **Nicolás**. Actualmente curso el **4° año de Ingeniería en Sistemas de Información** en la **UTN - Facultad Regional Córdoba** (con paso previo por Ciencias de la Computación en la UNC). Me apasiona construir herramientas prácticas, experimentar con servidores propios y entender a fondo cómo funcionan las cosas por detrás.

- 🧭 **Curiosidad & Camino:** Orientado hacia la **Ciberseguridad**, la **Gestión de Redes de Información** y las arquitecturas resilientes.
- 🤖 **Experiencia en IA:** Me desempeñé como **QA Junior en Inteligencia Artificial para Outlier**, evaluando, testeando y refinando el razonamiento y alineamiento de LLMs avanzados.
- 🏠 **Homelab & Soberanía de Datos:** Administro mi propio servidor doméstico 24/7 impulsado por Debian, Docker Compose, Caddy y túneles Cloudflare Zero Trust.
- 🛠️ **Desarrollo:** Fuerte afinidad con **Python** (**FastAPI**, **Flask**), **React / TypeScript**, aplicaciones móviles híbridas (**Capacitor**) y utilidades de automatización.

### 🍵 Arquitectura Homelab & Nodo Autohospedado

```text
                 [ Internet / Clientes Móviles ]
                                │ 
                 (Túnel Seguro Cloudflare Zero Trust)
                                │
  ┌─────────────────────────────▼───────────────────────────────────┐
  │                 HOMELAB SERVER (Debian Linux)                   │
  │                                                                 │
  │  🌐 APLICACIONES & HUBS   🛡️ RED & DNS           🔐 SEGURIDAD   │
  │  ├─ Portfolio Hub         ├─ AdGuard Home (DNS)  └─ Vaultwarden │
  │  ├─ Kairós UTN            └─ Tailscale Mesh Net                 │
  │  ├─ El Canuto                                                   │
  │  └─ Track Backend         📈 TELEMETRÍA          ⚡ REVERSE PROXY│
  │                           ├─ Uptime Kuma         └─ Caddy Proxy │
  │  📦 ORQUESTACIÓN          └─ Glances Metrics                    │
  │  └─ Docker Compose                                              │
  └─────────────────────────────────────────────────────────────────┘
```

* 🛡️ **Seguridad Perimetral:** Cloudflare Zero Trust Tunnels y Tailscale Mesh (cero puertos abiertos en el router residencial).
* ⚡ **Reverse Proxy:** Caddy gestionando nombres de dominio internos y certificados TLS automáticos.
* 📈 **Telemetría & Salud:** Uptime Kuma para seguimiento continuo de latencia y Glances para métricas de hardware.
* 🔐 **Privacidad:** AdGuard Home para filtrado DNS de red y Vaultwarden con respaldos periódicos cifrados.
